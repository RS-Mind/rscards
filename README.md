# rscards
Cards for ROUNDS focused on adding variety with vanilla stats

## Current Card List:

### Bounce Absorption
[Uncommon]

- +100% DMG
- +50% Bullet speed
- -2 Bullet bounces

### Changeup
[Common]
Bullets keep the default trajectory
- +50% ATKSPD
- -30% Projectile Speed

[Common]

- +30% Damage
- +0.25s Block cooldown

### Hitscan

- No Bullet gravity

[Common]
A twin scythe will orbit you, dealing damage and destroying bullets.

This card will not work in sandbox without using Sandbox Improvements.
This card will not appear if RSClasses is installed, being replaced by the Astronomer class.
